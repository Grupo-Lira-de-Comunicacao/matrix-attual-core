# Decisões de nomenclatura corporativa

## Plataforma Attual

Status: vigente

A partir de 2026-09-08, **Plataforma Attual** é o nome corporativo/oficial a utilizar no lugar de **Attual App**.

Regras:

- Usar **Plataforma Attual** em documentação, arquitetura, apresentações, relatórios e interfaces novas.
- Não criar novas referências de negócio com o nome **Attual App**.
- Identificadores técnicos existentes (IDs de projeto, refs Supabase, slugs, nomes de repositório, variáveis e chaves) não devem ser renomeados automaticamente apenas por causa desta decisão, para evitar quebra operacional.
- Quando um nome técnico legado precisar permanecer, documentar que ele pertence à **Plataforma Attual**.
- Alterações futuras de nomes técnicos devem ser feitas como migração controlada, com inventário de dependências.

Esta decisão substitui a nomenclatura corporativa anterior `Attual App`.
